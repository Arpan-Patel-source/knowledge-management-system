# Knowledge Management System

A full-stack Knowledge Management System built using Spring Boot, React, and JWT authentication. The platform enables secure document management, verification, blockchain-based integrity tracking, and trust score analysis.

## Features

- JWT Authentication & Authorization
- Role-Based Access Control
- Secure Document Upload & Verification
- Blockchain-Based Document Integrity
- QR Code Verification
- Audit Logs
- Trust Score System
- Swagger API Documentation
- Responsive Frontend UI

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Security
- JWT
- Maven
- JPA/Hibernate

### Frontend
- React.js
- Vite
- Axios
- React Router

### Database
- MySQL
